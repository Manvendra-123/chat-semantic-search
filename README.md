# Search a Group Chat Properly

A semantic search engine designed to find meaning in a messy, Hinglish group chat where messages often have zero word overlap with the query. 

## Features
- **Hybrid Search Algorithm**: Combines TF-IDF, Character N-Grams, and LSI (Latent Semantic Indexing) to match both meaning and misspellings in Hinglish.
- **Intent Boosts**: Automatically boosts relevance based on identified persons (e.g., "Priya", "Rohit") and timeframes ("last month", "July").
- **Conversational Context**: Returns the message inside a contextual window of surrounding messages, presented in a WhatsApp-like UI, solving the problem of a matching message being useless when ripped out of context.
- **Modern Vibe-Coded UI**: Dark mode, glassmorphism, smooth animations, and interactive chat bubbles.

## How to Run

1. **Install Dependencies**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

2. **Generate Synthetic Corpus and Run Evaluation**
   *(Note: This is already done in the repository, but you can run it again to verify)*
   ```bash
   # Generates 4000+ messages and queries
   python -m chatsearch.generate
   
   # Evaluates the queries against the index and reports accuracy
   python -m chatsearch.eval
   ```

3. **Start the Web UI**
   ```bash
   python -m chatsearch.serve
   ```
   Open `http://127.0.0.1:8000` in your browser. The first search takes a few seconds to build the LSI index.

## What is Mocked
As per the assignment constraints, **real chat data is not used**. 
- **The Corpus**: The group chat data is synthetically generated by `generate.py`. It uses a deterministic random seed to build over 4,000 messages from 8 participants over 6 months. It purposefully injects Hinglish, typos, short messages, and three main "decision threads" to simulate a real college group chat.
- **The Users & Identities**: All 8 participants (Rohit, Sneha, Ankit, Devansh, Aman, Priya, Kritika, Ishaan) and their interactions are mocked.
- **The Events**: The events discussed (Manali trip, tech fest, major project) are completely synthetic.

## Evaluation Results
The project contains 40 evaluation queries, out of which 8 are hard "zero-overlap" queries where the search string shares no words with the target message. 
The evaluation script (`chatsearch.eval`) automatically measures the retrieval accuracy. Because the corpus is designed to be highly difficult (lots of "haan", "ok", missing context), the `hit@1` gap between the warm-up queries and the hard queries represents the true capability of the hybrid search.
